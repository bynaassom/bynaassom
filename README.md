## A project I'm proud of

### 🥊 UFC Fantasy

[**github.com/bynaassom/ufc-fantasy**](https://github.com/bynaassom/ufc-fantasy)

An independent UFC prediction and fantasy platform that I built to explore what it takes to turn an idea into a real, working product.

The project includes:

* user authentication
* predictions and scoring
* rankings and private leagues
* PostgreSQL database
* external data synchronization
* background jobs
* notifications
* automated tests
* CI/CD
* PWA support
* production deployment

**Stack:** Next.js · React · TypeScript · Supabase · PostgreSQL · Tailwind CSS · Vitest · Playwright

The project is especially important to me because it became a way of learning things that I had not yet studied formally: how to structure an application, model data, debug production issues, work with external services, write tests and gradually improve a system as it grows.

[**View the project →**](https://github.com/bynaassom/ufc-fantasy)

## How I learn

I learn primarily by **building things**.

When I don't know how to do something, I try to understand the problem first, research possible approaches, implement a solution, test it, and then revisit the parts I don't understand.

AI is also part of my workflow. I use it to explore ideas, investigate bugs, review decisions and help me understand unfamiliar concepts.

But the goal is not simply to generate code.

The goal is to **understand the code I build and become better at solving problems without it.**
